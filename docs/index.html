折扣率＝銷貨金額 ÷ 市價；市價＝拆組後數量 × NS 售價（Base Price × 1.05，台幣）。含 0 元贈品，海外通路也用台灣牌價（TW）。

銷售金額

銷售數量

系列別 × 規格前三碼 × 規格前六碼 × 銷貨年月

點 ⊞ 展開系列或前三碼（像 Excel 群組）。每組第一列「Total」為小計，依總計由大到小排序；沒有資料的月份留空，有資料但加總為 0 顯示 0。下載的 Excel 一律是全部展開。

By 通路別（可展開至品號）

占比＝占所選範圍本期（前期）總金額；折扣率＝銷貨金額 ÷ 市價（數量 × NS 售價）；本年累計＝本期所在年度 1 月至本期；成長率、折扣率增減為本期 vs 前期。各層依本期金額由大到小排序。

未對到品號

幣別與其他月份不一致

該通路其他月份用外幣、這個月填 NTD／匯率 1，且金額落在外幣的量級（與彙總表不符），疑似原幣直接當台幣。一直以台幣交易的經銷商通路不會列在這裡。請業務確認。

通路調整

build/通路類別調整.csv（或上傳的「通路別、通路名稱、通路類別、說明」CSV）覆蓋通路對照的通路名稱與通路類別，留空＝不改；地區、備註不變。黃底＝通路別不在通路對照（沒有套用，請檢查是否打錯），或同一通路別有多列、這一列被後面的列覆蓋。

裸瓶對應正貨（拆組後）

NS 組包 BOM 的成分是裸瓶（半成品）時，拆組後改以對應的正貨品號顯示（品名、系列跟正貨），市價仍用裸瓶（BOM 成分）售價，與業務參考值口徑一致；表中「正貨牌價」僅供參考。黃底＝規格版本不同或找不到正貨，請確認；要手動指定，上傳含「裸瓶品號、正貨品號」兩欄的 CSV（或編輯 build/裸瓶對照.csv）。

系列歸類不一致（同一前三碼掛在不同系列）

依拆組後、有銷售的品項計算。黃底＝不是該前三碼金額最大的系列，多半是 NS 品項的系列欄位掛錯（不是系列改名），請 NS 主檔確認；修正後重新匯出 NS 維度表即可。確認無誤的品號加到 build/系列確認.csv（或上傳含「系列確認品號」欄的 CSV）就不再提醒。

目前資料

① 上傳新資料

  • sell-out 明細（必要）：業務每月的《yyyy年度 SellOut 明細表》.xlsx。檔案裡的年度會整年取代，其他年度保留（例：另外上傳含「2025年度」工作表的檔案就能補上 2025）
  • 通路對照（選用）：明細出現新通路時，先「下載通路對照表」加一列再上傳
  • 通路調整（選用）：CSV「通路別、通路名稱、通路類別、說明」（同 build/通路類別調整.csv），覆蓋通路對照的通路名稱、通路類別，留空＝不改；上傳新的通路對照時調整照樣套用
  • 補充 BOM（選用）：CSV「組包品號、成分品號、用量、分攤比例」，NS 沒有 BOM 但要拆的組包（兩種 BOM 模式都會用）
  • 裸瓶對照（選用）：CSV 兩欄「裸瓶品號、正貨品號」，手動指定拆組後裸瓶要對應的正貨
  • 系列對照（選用）：NS 系列改名時，下載系列對照表（原系列名稱 → 報表系列名稱）加一列再上傳
  • NS 維度表（選用）：匯出程式產生的 D_Item.csv、D_BOM.csv、D_BOM_補.csv

② 發布給所有人

上傳的資料只在你這個分頁有效（重新整理就會消失）。確認數字沒問題後：

  1. 按 （用目前的密碼加密）
  2. 開啟 GitHub 上傳頁（docs 資料夾），把 data.enc 拖進去，按「Commit changes」
  3. 約 1 分鐘後網站更新，所有人重新整理就會看到新資料

也可以在電腦上執行 07_網頁報表\更新報表資料.bat：它會用電腦上的原始資料（03_原始資料_業務提供、NS 匯出、build 資料夾的對照表）整份重建，會取代之前在這裡上傳發布的版本；網頁上傳時用的對照表（通路、通路調整、系列、裸瓶、補充 BOM）如果要保留，請一併放到電腦上的對應檔案。
